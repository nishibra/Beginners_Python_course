## ■ カリキュラム構成（全6回 / 3ヶ月間）

### 【第1回】 【準備編】Pico超入門 と プログラミングのきほん（10月17日（土）10:00-12:00）[cite: 114]
* Zoomでのオンライン受講方法と環境チェック、Thonny（ソニー）の使い方マスター[cite: 114]
* MicroPythonの基本（数字・計算・「もし〜なら」・「くりかえし」）[cite: 114]
* オンボードLEDをプログラミングでピカピカ光らせる「Lチカ」ミッション！[cite: 114]

### 【第2回】 ロボットの足（KRSサーボモータ）を自由自在に動かそう！（11月上旬（土）予定）[cite: 114]
* 普通のモータとサーボモータの違い（指定した角度でピッタリ止まる仕組み）[cite: 114]
* シリアル通信（UART）を使って、Picoからモータへ「○度へ動け」と命令送信[cite: 114]
* モータを首振りのように滑らかに往復運動させるプログラムを作成[cite: 114]

### 【第3回】 高性能IMUセンサ（GY-BNO055）でロボットの「へいこうかんかく」を測ろう！（12月上旬（土）予定）[cite: 114]
* 本格9軸センサ GY-BNO055 の特徴とI2C通信での接続方法[cite: 114]
* センサ内部のフュージョン機能を使って「正確な傾き角度（オイラー角）」を即座に取得[cite: 114]
* Picoを傾けるとパソコン画面の角度表示が滑らかに反応するリアルタイム実験[cite: 114]

### 【第4回】 たったまま倒れない「コントロールの魔法（PID制御）」（12月下旬（土）予定）[cite: 114]
* 「手のひらでほうきを立てる遊び」から、比例(P)・積分(I)・微分(D)の感覚を直感体験[cite: 114]
* 傾きにあわせてモータをどちらへどれくらい回すか計算するバランス計算プログラム作成[cite: 114]
* 画面上のシミュレーション画面で、画面の中のロボットを立たせるテスト[cite: 114]

### 【第5回】 ぜんぶ合体！はじめての倒立（とうりつ）テスト（1月中旬（土）予定）[cite: 114]
* 1秒間に100回（10ms周期）正確に計算をまわすタイマー[cite: 114]
* GY-BNO055センサ読み取り → バランス計算 → モータ出力の一連ループを合体して実機テスト！[cite: 114]
* 倒れそう（±45度超）になったら自動でモータを止める「転倒安全ブレーキ」の組込[cite: 114]

### 【第6回】 倒れないロボット完成！ふんばりコンテスト＆オンライン発表会（1月下旬（土）予定）[cite: 114]
* パラメータ（P・I・Dの強さ）を調整して一番シャキッと立つベストな数値を捜索[cite: 114]
* 手でちょんと押しても倒れずに起き上がってくる「おきあがりこぼし」調整[cite: 114]
* Zoom画面越しに手放しで何秒立ちつづけられるかタイムアタック＆発表会！[cite: 114]
